## 🔄 How Everything Works

1. **User launches app** → boot.html loads
2. **Loading animation plays** → 1.5 seconds
3. **Transitions to lobby** → bio_lobby3.html
4. **User clicks a game button** → Navigates to respective screen
5. **Game screen loads** → Full functionality available
6. **User clicks Back** → Returns to lobby
